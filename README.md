# Crew Panic Customizer for Gunner HEAT PC!

Version 1.0. GHPC Crew Panic Customizer. Allows you to set the panic level of crews. Use the MelonPreferences.cfg file to configure the settings.

***Installation***  
This mod requires MelonLoader Version 0.6.1.

To install, extract the "Crew_Panic_Customizer.dll" file from releases and put it into the mod folder.
